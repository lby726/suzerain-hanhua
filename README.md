## 特点

- 面向《Suzerain》完整简体中文汉化
- 术语整理统一，剧情翻译完整

## 安装

1. 下载最新汉化包：前往右侧 **Releases** 页面，选择最新版本下载汉化压缩包。
2. 解压后，将汉化文件放入游戏安装目录对应位置（覆盖前请先备份原文件）。
3. 启动游戏，在设置中选择简体中文（如游戏内可切换语言）。

> 需要您已**合法购买并拥有**《Suzerain》游戏副本。
